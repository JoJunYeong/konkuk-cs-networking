# 온오프믹스 행사 운영 체크리스트

이 사이트는 행사 소개와 브랜드 화면만 담당한다. 신청자 개인정보, 결제, 취소·환불, 참석자 공지는 온오프믹스에서 관리한다. ZADU 결제 계정이나 코드는 사용하지 않는다.

## 1. 행사 만들기

관리자 화면의 `온오프믹스 행사 만들기`를 누르고 다음 내용을 먼저 확정한다.

- 행사명과 주최자 표시명
- 신청 기간, 행사 날짜와 시간
- 참가비, 정원, 1인 신청 가능 수량
- 취소·환불 마감일과 기준
- 공개 장소 범위와 결제 완료자에게만 보낼 정확한 주소
- 이름, 휴대전화, 이메일, 학번·졸업연도 등 꼭 필요한 신청 질문

필요하지 않은 개인정보는 받지 않는다. 행사 페이지를 공개하기 전에 온오프믹스의 최신 결제 수수료와 정산 조건을 [공식 FAQ](https://corp.onoffmix.com/faq)에서 다시 확인한다.

## 2. 이 사이트와 연결하기

1. 온오프믹스에서 공개 행사 URL을 복사한다.
2. 이 사이트의 `/admin.html`에 로그인한다.
3. `분기별 행사`에서 공개할 회차를 고른다.
4. `공개 신청 URL`에 주소를 붙인다.
5. 상태를 `신청 가능`, 상태 문구를 `신청 가능`, 버튼 문구를 `신청·결제하기`로 바꾼다.
6. 저장하고 `공개 페이지 보기`에서 데스크톱과 모바일 버튼을 확인한다.

URL이 없거나 `https://`가 아니면 신청 버튼은 열리지 않는다.

## 3. 공지하기 전 테스트

실제 공지는 아래 확인 뒤에 보낸다.

- 테스트 신청 1건이 참가자 명단에 나타나는지
- 결제 완료 상태가 별도 수기 대조 없이 구분되는지
- 신청자에게 기본 확인 메일이 도착하는지
- 취소·환불 요청 경로와 주최자 처리 화면이 보이는지
- 운영자가 확정자만 골라 장소·입장 안내를 보낼 수 있는지
- 공개 페이지나 Firestore 자료에 정확한 장소와 참가자 정보가 없는지

## 4. 참석자 확정 뒤 장소 공지

온오프믹스의 개설내역에서 해당 행사의 신청자 관리 화면을 연다. 결제 완료·참여 확정 상태인 사람만 대상으로 정확한 장소, 입장 시간, 연락 방법을 이메일로 먼저 보내고 필요할 때 문자로 보완한다. 공지 제목에 행사 날짜를 포함하고, 발송 뒤에는 실제 수신 계정 1건으로 내용을 확인한다.

결제·정산·문자 발송 비용과 기능은 바뀔 수 있으므로 운영 직전에 온오프믹스 화면의 최신 조건을 기준으로 한다.
